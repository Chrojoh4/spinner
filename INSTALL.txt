012 SPIN — SAME INSTALLATION APPROACH AS C-WAGS TRACKER

1. Create a new GitHub repository for this app, for example 012-spin.
2. Upload the CONTENTS of this folder into its root: index.html, app.js,
   style.css, sw.js, manifest.webmanifest, icons folder and .nojekyll.
3. In repository Settings > Pages, select Deploy from a branch, main,
   / (root), then Save.
4. When GitHub reports the site is live, open that link in Chrome on Android.
5. Tap Install app if offered, or Chrome menu > Add to Home screen > Install.
6. Wait for the offline status to say Ready for offline use. The installed
   app then opens from its home-screen icon and works without internet.

Opening index.html as a downloaded file previews the spinner but cannot
install the app. Installation requires an HTTPS hosted link.

Every spin finishes within about one second (immediate if reduced motion is
enabled). Every result uses 0, 1, and 2 once. Repeating the previous order is
possible. No account, advertising, analytics or external libraries.

When changing app files, increment the CACHE version in sw.js, and upload
the complete app folder. The old app cache is removed on activation.
